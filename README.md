# 建木挂机（安卓 APK v0.2，未编译验证）

无障碍服务：定时截图 → 用 OpenCV 模板匹配找「收取一键」「派遣一键」（简体/繁体都认）→ 点击；
弹窗靠整屏亮度判断（变暗就点底部居中关闭）；找不到按钮时会先关建筑详情面板、再按上次成功的位置点。
OpenCV 加载失败时自动退回「固定位置点击」。每轮结束等一个间隔再来一轮。
要求 Android 11 及以上，只打了 arm64-v8a（现在的手机基本都是）；APK 因为带 OpenCV，会比 v0.1 大十几 MB。
依赖：org.opencv:opencv:4.9.0（Maven Central）。

## 一、生成 APK（不装 Android Studio，用 GitHub 自动构建）
1. 登录 GitHub，新建一个仓库（私有也行）。
2. 把本文件夹里的**所有文件**上传到仓库根目录（网页上 Add file → Upload files，直接拖进去）。
   注意 `.github` 文件夹必须一起上传。
3. 仓库顶部 Actions → 左侧 Build APK → Run workflow（上传后也会自动触发）。
4. 等几分钟变绿，点进这次运行，页面底部 Artifacts 里下载 `jianmu-auto-apk`，解压得到 `app-debug.apk`。
5. 如果变红：点开失败的步骤，把红色报错复制给我。

（备选）用 Android Studio 打开本文件夹，等 Gradle 同步完，Build → Build APK(s)。

## 二、安装和使用
1. 手机安装 `app-debug.apk`（允许安装未知来源应用）。
2. 打开应用，点「打开无障碍设置」，找到「建木挂机」并开启。
   小米/HyperOS 若开关是灰的：设置 → 应用 → 应用管理 → 建木挂机 → 右上角「⋮」→「允许受限设置」，再回来开启。
3. 回到应用，顶部应显示「无障碍服务：已开启」；日志里应有「OpenCV 已加载，使用图像识别」。
   如果写的是「OpenCV 加载失败」，说明走了固定位置模式，把这行和手机型号发我。
4. （推荐）点「检测游戏包名」，8 秒内切到游戏，再回到本应用，包名会自动填入。
   填了之后，游戏不在前台时脚本会跳过本轮，不会点到别的应用。
5. 设好间隔（分钟）和开始前等待（秒），点「开始」，在倒计时内切到游戏的建木培植主界面（右下角快捷栏展开）。
6. 保持游戏在前台、屏幕常亮（开发者选项里打开「充电时不锁定屏幕」，或把休眠时间调到最长）。
7. 想停止：回到本应用点「停止」。

## 已知限制
- 识别只覆盖：收取一键、派遣一键、建筑详情面板的关闭键。游戏停在别的界面时，会跳过那一轮（日志里有「没找到…」）。
- 弹窗仍然靠亮度判断，不识别具体是哪个弹窗。
- 游戏若设置了禁止截屏，截图会是黑的，本应用就会一直点底部居中。
- 手机基本被占用；后台省电策略可能杀掉服务，请把本应用设为「无限制」。
